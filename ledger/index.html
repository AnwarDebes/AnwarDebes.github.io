The film's ledger

Every source the film Show Its Work puts on screen, in the order it appears: 541 entries, each hashed and chained to the one before. Hash-chained, not signed: anyone can recompute it.

Head hash

6578f88114dce6bc539e7ac36218a454391981e8bdb6d1064d3382f201481dc2

505file@commit: the cited file at its pinned commit
26capture: a screen recording or terminal capture
5commit: the commit itself
5api-snapshot: a saved GitHub API response

Check it yourself

git clone https://github.com/AnwarDebes/anwar-debes-film
cd anwar-debes-film
node verify-ledger.mjs

It clones every cited repository fresh from GitHub, reads each file at its pinned commit, re-hashes every source and recomputes the chain. Each link is the SHA-256 of the previous link, a newline and the entry's type, id and hash, starting from the SHA-256 of film-ledger v0. The last line it prints is the head hash above, and the last chapter of the film plays a recorded run of exactly this.
